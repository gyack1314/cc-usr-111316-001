# 部门会计资料

Z行供给、列使用，Y行供给、列目的地，f为直接排放，x为总产出。量用精确非负有理字符串，同一币值单位。缺行列不等于0；empty是有完整0行0列的真实空部门。容差仅供数值证据，不能放宽会计或非负输入。

情景对A的指定单元置0，不重新用原x缩放，也不把原会计约束当成情景仍须满足的恒等式。direction是对A的导数方向，非对Z。生产性以非负A的谱半径小于1或等价M矩阵证据说明；已平衡表也可能近奇异。

读取工具（`inspect`）只清点矩阵维度和部门身份，不计算A、乘数、足迹或任何情景结论。

# 核算工具（`run`/`demo`）

`analysis_data.mrio` 在上述口径上执行核算，全部量以精确有理数(Fraction)计算：

- 校验：缺项、负量、浮点、形状错误、会计不平衡（rowsum(Z)+rowsum(Y)≠x）一律拒绝；零产出部门仅当交易（行与列）、最终需求、排放全零才剔除并保留映射，否则拒绝，不除零也不以小常数填补。
- 求解：A=Z·diag(x)⁻¹，g=f/x，L=(I−A)⁻¹ 精确求得，残差恒为0。生产性证据为 Hawkins-Simon 主元全正且 L 非负；另报告谱半径行和界与幂法估计（仅供诊断）。条件数（1-范数，精确）超过 condition_limit 视为近奇异。非生产性或近奇异时阻止正式结论：包状态 blocked，责任/情景/导数为 null，仅保留证据。行列平衡通过不等于可解。
- 责任：按目的地给出 g_i·(L·Y)_ik、总量、直接与间接互补分解；层级序列为增量 c_m=g·A^m·Y_k 加精确余量，不是总乘数，不可逐层重复累加。各目的地合计精确等于保留部门直接排放合计。
- 情景：登记的 extraction_cells 置零后重新解产出与足迹，给出前后对照；这是假设投入被无排放替代的结构反事实，非因果预测。
- 导数：A(t)=A+t·D 在 t=0 的解析方向导数 dF/dt=g·L·D·L·Y；以步长 1/10…1/10⁶ 的精确差分复核（中心优先，单侧不可行退化为单侧）。扰动使系数为负、非生产或条件数超限即跨到不可行域，该步长不参与有效性判断；全部步长不可行时不报有效弹性。elasticity_per_unit_t=(1/F)·dF/dt。
- 拆分汇回：split_sector 把一个部门按份额拆成两个同比例子部门（相同列技术、相同直接强度），merge_sectors 汇回；拆分前后各目的地足迹精确不变。

分析包保存：部门映射、会计差异、求解证据（主元、Leontief 逆、条件数、残差、谱半径界）、各目的地责任、情景前后对照、导数与差分复核。输入非法时不产出任何分析包。
